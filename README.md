# 🛍️ Cloth Store

A modern e-commerce clothing store built with **Next.js**, **Tailwind CSS**, and **TypeScript**. This project showcases a responsive UI, product listing, filtering, and basic e-commerce functionality.

---

## ✨ Features

- 🚀 Built with **Next.js** and **TypeScript**
- 🎨 Styled with **Tailwind CSS**
- 📦 Product listing and category filtering
- 🔍 Clean and responsive UI
- ⚡ Optimized performance and code structure
- 📁 Organized folder structure for scalability

---

## 🧰 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Heroicons](https://heroicons.com/)
